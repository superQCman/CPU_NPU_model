# 交付清单

## 已包含内容

| 目录 | 内容说明 |
|---|---|
| `code/` | 最终交付脚本，包括训练、语义特征构建、图表生成、targeted case 生成和 DLRM 验证。 |
| `input_data/` | 交付内置输入数据，包括训练数据集和轻量级 DLRM 验证 profile。 |
| `models/` | 本次建模使用的 NPU 硬件描述文件。 |
| `results/` | 最终数据快照、预测结果、验收指标、交付报告和模型 artifact。 |
| `results/dlrm_end_to_end/` | 多配置 DLRM held-out NPU replacement 验证结果。 |
| `docs/` | 建模方案、使用说明和建模原理文档。 |
